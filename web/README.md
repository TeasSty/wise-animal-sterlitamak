# WISE ANIMAL — сайт-концепт

Концепция: **«Кинологический двор»** (см. `../DESIGN-BRIEF.md`).

## Запуск

```bash
cd web
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

Фото на концепте — стоковые placeholders документального характера. В финале заменить кадрами базы, занятий и гостиницы из VK / съёмки.
